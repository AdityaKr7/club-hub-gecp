## 💾 Data & Backend

✨ **Good news!** All data is saved locally in your browser.
- No server setup needed
- No database required
- Data persists between sessions

### Reset Data
1. Open DevTools (F12)
2. Application → Local Storage
3. Delete entries starting with `club_hub_`
4. Reload page

## 🔧 Troubleshooting

| Issue | Solution |
|-------|----------|
| Page won't load | Check browser console (F12) |
| Data not saving | Clear browser cache and reload |
| Login not working | Use exact credentials from table above |
| Mobile issues | Zoom reset (Ctrl+0) |
