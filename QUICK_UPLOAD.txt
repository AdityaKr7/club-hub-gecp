# 📤 QUICK UPLOAD COMMANDS

Copy and paste these commands in order. Takes ~5 minutes!

---

## 🟦 Windows PowerShell (Recommended)

### Step 1: Navigate to Project
```powershell
cd "C:\Users\adity\Code\CLUB HUB 2"
```

### Step 2: Initialize Git
```powershell
git init
```

Expected output:
```
Initialized empty Git repository in C:\Users\adity\Code\CLUB HUB 2\.git\
```

### Step 3: Configure Git (First Time Only)
```powershell
git config --global user.name "Your Full Name"
git config --global user.email "your.email@gmail.com"
```

Replace with your actual name and email.

### Step 4: Add All Files
```powershell
git add .
```

Verify:
```powershell
git status
```

Should show green "new file" entries.

### Step 5: Create First Commit
```powershell
git commit -m "Initial commit: CLUB HUB GECP - Campus Club Management System"
```

Expected output:
```
[main (root-commit) xxxxx] Initial commit: CLUB HUB GECP
 15 files changed, 8945 insertions(+)
 create mode 100644 .gitignore
 create mode 100644 README.md
 ... (and other files)
```

### Step 6: Rename Branch
```powershell
git branch -M main
```

### Step 7: Connect to GitHub

**FIRST:** Create a repository on GitHub:
1. Go to https://github.com/new
2. Repository name: `CLUB-HUB-GECP`
3. Description: `Campus Club Management System`
4. Choose: Public or Private
5. Do NOT check "Initialize with README"
6. Click "Create repository"

**THEN:** Run this command (replace `yourusername`):
```powershell
git remote add origin https://github.com/yourusername/CLUB-HUB-GECP.git
```

Example:
```powershell
git remote add origin https://github.com/john-doe/CLUB-HUB-GECP.git
```

### Step 8: Push to GitHub
```powershell
git push -u origin main
```

**First time?** Enter your:
- Username: your GitHub username
- Password: Your Personal Access Token (not your password!)

**What's a PAT?**
1. Go to GitHub Settings → Developer settings → Personal access tokens
2. Click "Tokens (classic)"
3. "Generate new token"
4. Check ✅ repo
5. Copy the token
6. Paste when prompted for password

Expected output:

## 🆘 Common Issues

### "fatal: not a git repository"
```
Solution: Run 'git init' first
```

### "Permission denied (publickey)"
```
Solution: Use HTTPS instead of SSH
```

### "Could not read Username"
```
Solution: Use Personal Access Token, not your password
```

### "everything up-to-date"
```
Solution: Your code is already uploaded! ✅
```

### "remote origin already exists"
```powershell
Solution:
git remote remove origin
git remote add origin https://github.com/yourusername/CLUB-HUB-GECP.git
```
